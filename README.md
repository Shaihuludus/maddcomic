# MaddComic

An application for reading comics in .cbz format.

Written in Vue and Rust using Tauri

## Compiling and running the app

### Requirements

 For compiling and running from source code its the same as Tauri
 
https://v2.tauri.app/start/prerequisites/

### Running
There is Intelij Run configuraton added with project or you can use command line
```
npm run tauri dev
```
